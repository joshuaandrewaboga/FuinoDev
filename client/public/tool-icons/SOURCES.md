# Technology icon sources

Brand marks identify the corresponding technologies; they do not imply endorsement.

- SVG Logos, by Gil Barbara, via `@iconify-json/logos` (CC0): https://github.com/gilbarbara/logos
- Simple Icons, via `@iconify-json/simple-icons` (CC0): https://github.com/simple-icons/simple-icons
- Arcjet favicon: https://arcjet.com/favicon-light.png
- Site24x7 favicon: https://img.site24x7static.com/images/site24x7-fav.ico
- Junie product mark: static SVG paths from https://junie.jetbrains.com/assets/junie-logo-DuptOByp.js (official product page: https://www.jetbrains.com/junie/).

All assets are served locally. No visitor requests to logo providers are needed. Brand trademark rights remain with their owners. Lucide symbols represent concepts without a distinct product mark (SQL, REST, networking, security mechanisms) and tools without a supplied brand mark (Helmet, Supertest). Unknown custom tools receive a code symbol, never unrelated brand artwork.

To rebuild the collection-based assets: `node scripts/generate-tool-icons.mjs`. The three official website assets are stored alongside the generated SVGs and preserved by the generator.
